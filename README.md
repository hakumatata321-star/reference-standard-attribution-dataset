# Reference Standard Attribution Dataset

Calibration records with the traceability links removed: 1,500 synthetic laboratories, 7,444 reference
standards, 18,513 instruments and 961,908 check readings over 730 days.

Every instrument is periodically re-calibrated against exactly one of its laboratory's reference
standards, which pins its readings to that standard's value on the day of the calibration; between
calibrations it drifts on its own. Which standard each instrument belongs to is the one thing the records
do not contain, and it is what this dataset asks you to recover. Each standard serves exactly the same
number of instruments, so the assignment is a fully subscribed matching rather than a set of independent
labels.

- **Origin:** fully synthetic, generated by the creator. Every draw and identifier derives from
  HMAC-SHA256 keyed to a withheld secret; the generator code and the secret are not published. No real
  operational records, no personal data and no third-party material.
- **Files:** `labs.csv`, `standards.csv`, `certificates.csv`, `instruments.csv`, `readings.csv`,
  `calibrations.csv`, `assignment.csv`, plus `source_metadata.json`, `DATASET_CARD.md`,
  `DATASET_DESCRIPTION.md`, `ATTRIBUTION.txt` and `LICENSE`.
- **Full documentation:** [DATASET_DESCRIPTION.md](DATASET_DESCRIPTION.md).
- **Intended use:** research and benchmarking of constrained assignment recovery from sparse, noisy
  measurement records.
- **Out of scope:** any claim about real laboratories, instruments or measurement standards.
